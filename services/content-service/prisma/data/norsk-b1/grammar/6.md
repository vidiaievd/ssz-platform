# GRAMMATIKK — Relativsetninger (относительные придаточные)

Относительное придаточное описывает существительное. Оно вводится словом `som` и др.

## 1. som — базовое относительное слово

`som` = «который/которая/которые» для людей и вещей.

- Nyheter **som** er falske, spres raskt. (som = подлежащее — опускать НЕЛЬЗЯ)
- Avisa **(som)** jeg leser, er seriøs. (som = дополнение — можно опустить)

## 2. Предлог уходит в конец

В норвежском предлог ставится **в конце** придаточного, а не перед `som`.

- Mannen **som** jeg snakket **med**, er journalist. (не «med som»!)
- Huset **som** vi bor **i**, er gammelt.

## 3. der / hvor — для места

Для обстоятельства места вместо «som … i/på» часто `der` или `hvor`.

- Et sted **der** vi ikke trenger telefonene. (= som vi ikke trenger telefonene på)
- Byen **hvor** jeg vokste opp, er liten.

## 4. det som / alt som — «то, что / всё, что»

- **Det som** du legger ut, kan bli liggende. (то, что…)
- Jeg tror på **alt som** hun sier. (всё, что…)

## Таблица

| Функция som | Опускается? | Пример |
|---|---|---|
| подлежащее | НЕТ | Folk som lyver … |
| дополнение | да (необяз.) | Boka (som) jeg leser … |
| место | der/hvor | Stedet der vi møttes … |

## Мнемоника

**som er subjekt → må stå. som er objekt → kan droppes. Preposisjon HELT til slutt.
Sted → der/hvor.**
