# GRAMMATIKK — Tekstbinding og ordlaging

## 1. Наречия-связки и инверсия

Слова-связки в начале главного предложения вызывают **инверсию** (глагол на 2-й
позиции). Систематизация пары «союз ↔ наречие»:

| Придаточный союз (subjunksjon) | Наречие-связка (adverb) | Значение |
|---|---|---|
| fordi | **derfor** | причина → следствие |
| selv om | **likevel** | уступка |
| — | **dessuten** | добавление (к тому же) |
| men | **imidlertid** | однако (формально) |
| — | **altså** | итак, то есть |
| — | **for eksempel** | например |
| — | **til slutt** | наконец |

Примеры (инверсия!):

- Jeg var ensom. **Derfor** meldte jeg meg inn i et kor.
- Norsken er bra. **Dessuten** blir den bedre mens du jobber.
- Det var vanskelig. **Likevel** ga hun ikke opp.

## 2. Союз против наречия — порядок слов

- **Fordi** jeg var ensom, meldte jeg meg inn i et kor. (союз + прямой порядок в придат.)
- Jeg var ensom. **Derfor meldte** jeg meg inn. (наречие + инверсия)

## 3. Словообразование (ordlaging)

**Приставки:**

| Приставка | Значение | Пример |
|---|---|---|
| u- | отрицание | **u**mulig, **u**vanlig, **u**enig |
| mis- | неправильно/плохо | **mis**forstå, **mis**lykkes |
| gjen- | заново/обратно | **gjen**bruk, **gjen**vinne |

**Суффиксы существительных:**

| Суффикс | От чего | Пример |
|---|---|---|
| -het | прилагат. → сущ. | mulig → mulig**het**, ensom → ensom**het** |
| -else | глагол → сущ. | oppleve → oppleve**lse** |
| -ing/-ning | глагол → сущ. | utdanne → utdann**ing**, forandre → forandr**ing** |
| -er | глагол → деятель | lære → lær**er**, arbeide → arbeid**er** |

**Сложные слова (sammensatte ord):** последнее слово — главное, оно задаёт род.

- arbeid + plass = **en** arbeidsplass; jobb + intervju = **et** jobbintervju.

## Мнемоника

**Subjunksjon (fordi, selv om) → leddsetning. Adverb (derfor, likevel, dessuten) →
inversjon. u- = ikke, mis- = feil, -het/-else = substantiv.**
